GITHUB PAGES UPLOAD

1. Extract this ZIP first.
2. Open your GitHub repository.
3. Upload index.html AND the whole assets folder.
4. Do NOT upload the ZIP file itself.
5. Commit changes.
6. Go to Settings > Pages.
7. Under Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
8. Save and wait around 1-3 minutes.

Important:
- Keep the folder name exactly "assets".
- index.html must stay in the repository root.
